# Mango-LLM

A learning project: building a small-to-medium scale transformer language model 
entirely from scratch, then training it, all on a single laptop GPU (RTX 4050, 
6GB VRAM) plus free Google Colab compute for the full-scale run.

No pretrained/foundation model is used at any point — architecture, tokenizer, 
and training are all built and trained from the ground up.

## Status
Currently training the full-scale model (~330M parameters) on Google Colab.
